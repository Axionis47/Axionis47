# Tech stack badge assets

Local SVG badges keep the LangSmith and AWS icons available without relying on the badge service's logo catalog.

- LangSmith icon: [LobeHub Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/langsmith.svg), with the source license in `LICENSE-LobeHub`.
- AWS icon, also used on the Amazon Bedrock and Amazon S3 badges: [Devicon](https://github.com/devicons/devicon/blob/master/icons/amazonwebservices/amazonwebservices-plain.svg), with the source license in `LICENSE-Devicon`.

Badges add a label and background around each source icon. Product names and logos belong to their respective owners.
